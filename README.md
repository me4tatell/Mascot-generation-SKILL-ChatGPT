# Маскот Иван

Скилл Codex для создания и редактирования иллюстраций с корпоративным персонажем — антропоморфным носорогом Иваном.

Версия: **0.1.5**.

## Использование

В новом чате укажите `$ivan-mascot` и опишите задачу. Например:

> Используй $ivan-mascot. Создай одно изображение персонажа в строгом деловом костюме, по пояс, на белом студийном фоне. В руке папка с документами, на папке руна.

Для серии с открытым содержанием агент сначала предлагает сюжеты и постановки. При наличии готового задания приступает к генерации. Промпты и контроль результатов остаются работой агента.

## Что входит

- `SKILL.md` — основной порядок работы.
- `agents/openai.yaml` — название и описание в интерфейсе.
- `references/prompting.md` — правила подготовки промптов.
- `references/visual-guide.md` — роли и перечень изображений.
- `references/character/` — семь исходных визуальных эталонов персонажа.
- `references/environment/` — шесть примеров детализации окружения.
- `references/failures/` — семь примеров для анализа ошибок агентом, не для передачи в генератор.
- `references/manifest.json` — происхождение файлов, размеры и контрольные суммы.
- `scripts/save-result.ps1` — сохранение новых версий без перезаписи файлов в Windows.

Изображения оптимизированы в JPEG: персонаж до 1536 пикселей по длинной стороне, неудачные примеры до 1024; окружение сохраняет своё разрешение. Прозрачные области сведены на белый фон.

## Основные правила

Новые изображения и пересоздания строятся на визуальных референсах, которые передаются на вход генератору. Для локальной правки используется выбранная готовая картинка. Внешность лица не пересказывается словами; настроение и действие задаются постановкой. Руна — опциональный логотип с референсов, добавляемый точно и только по запросу.

Все версии изображений сохраняются отдельно. ZIP и контактные листы создаются только по прямой просьбе.

## Среда

Нужны Codex с доступным встроенным генератором изображений и доступ к локальным файлам референсов. Для штатного помощника сохранения нужен PowerShell в Windows.
